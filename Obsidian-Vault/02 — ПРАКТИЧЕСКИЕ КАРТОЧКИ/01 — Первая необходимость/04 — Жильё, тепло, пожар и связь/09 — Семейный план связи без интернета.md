# Семейный план связи без интернета

## Заполнить на бумаге

| Поле | Ваши данные |
|---|---|
| Точный домашний адрес и координаты |  |
| Ближняя точка встречи |  |
| Дальняя точка встречи, если район закрыт |  |
| Контакт за пределами района |  |
| Школа/сад/работа — план воссоединения |  |
| Кто забирает детей/помогает маломобильному |  |
| Местная Proteção Civil, полиция, пожарные |  |
| Станции радио и запасные частоты радиоприёмника |  |

Копия — у каждого взрослого, в рюкзаке, машине и у внешнего контакта. Не печатайте лишние медицинские/финансовые данные там, где лист может быть украден.

## При происшествии

1. Сначала спасайтесь, затем выходите на связь.
2. В угрозе жизни звоните **112**. Для медицинской триажной консультации без немедленной угрозы в Португалии — SNS 24, **808 24 24 24**.
3. Если голосовая сеть перегружена, отправьте короткое SMS: `ЖИВ/ТРЕБУЕТСЯ ПОМОЩЬ — место — куда иду — время`.
4. Не звоните всем по кругу. Один человек связывается с внешним контактом, остальные идут в точку встречи.
5. Не публикуйте в открытых соцсетях, что дом пуст, где лежат запасы и куда идут дети.

## Режим для группы 1–7

- Каждый доклад имеет форму: `КТО — ГДЕ — СОСТОЯНИЕ — НУЖНО — КУДА ИДУ — ВРЕМЯ`.
- Два фиксированных окна связи, например в каждый чётный час первые 10 минут. Между ними радио/телефон выключен или в экономии.
- Если связи нет, после безопасного времени ожидания все идут в точку встречи, а не ищут друг друга по нескольким маршрутам.
