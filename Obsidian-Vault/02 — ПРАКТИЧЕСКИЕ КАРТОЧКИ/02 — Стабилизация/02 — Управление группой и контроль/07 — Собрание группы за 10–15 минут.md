# Собрание группы за 10–15 минут

## Цель

Дать каждому одну и ту же картину, принять только необходимые решения и закончить встречу конкретными действиями. Собрание не заменяет немедленную эвакуацию, первую помощь или вызов 112.

## Когда применяется

- после первичной безопасности в первый час;
- утром и вечером в течение первых 72 часов;
- перед новым операционным периодом/сменой;
- после существенного изменения угрозы, состава или запасов;
- когда накопились противоречивые сообщения или задачи без владельца.

## До начала

Ведущий и записывающий готовят одну доску/страницу:

- время последнего обновления;
- перекличка;
- подтверждённые угрозы и официальные сообщения;
- прошлые три цели и их состояние;
- критические остатки;
- вопросы, требующие решения;
- место для новых задач.

Собрание проводится в безопасном и доступном месте. Человек с нарушением слуха/зрения, языковым барьером или ограничением движения должен получить информацию подходящим способом. Дети получают понятную информацию без пугающих подробностей и могут сообщить о своей потребности безопасному взрослому.

## Роли встречи

- **Ведущий** соблюдает порядок и время, не получает дополнительный голос.
- **Записывающий** фиксирует факты, решение, ответственного и срок.
- **Хронометрист** предупреждает об окончании пункта; роль можно совместить.
- **Участники** говорят коротко о наблюдениях, потребностях, рисках и обязательствах.

Если обсуждается действие ведущего или его конфликт интересов, этот пункт ведёт другой человек.

## Повестка на 12 минут

| Минуты | Пункт | Вопрос |
|---:|---|---|
| 0–1 | Открытие | есть ли непосредственная угроза прямо сейчас? |
| 1–3 | Люди | все ли учтены; кому нужна срочная помощь/доступность? |
| 3–5 | Обстановка | что подтверждено; что только сообщено; что изменилось? |
| 5–7 | Прошлые цели | выполнено, заблокировано, отменено — почему? |
| 7–9 | Ресурсы | что достигнет критического порога до следующей встречи? |
| 9–11 | Решения | до трёх целей; кто, с кем, к какому времени, стоп-условие |
| 11–12 | Повтор | каждый ответственный повторяет задачу; назначается следующая встреча |

Если требуется больше обсуждения, создайте отдельную встречу только заинтересованных взрослых. Не удерживайте всю группу.

## Формат короткого доклада

Каждый ответственный говорит не более минуты:

`ФАКТЫ — ЧТО СДЕЛАНО — ЧТО МЕШАЕТ — КАКОЕ РЕШЕНИЕ НУЖНО — ДО КАКОГО ВРЕМЕНИ`.

Пример формы, без заполненного содержания:

| Функция | Факты на время ___ | Выполнено | Риск/блокер | Нужное решение |
|---|---|---|---|---|
| Безопасность/медицина |  |  |  |  |
| Вода/пища/санитария |  |  |  |  |
| Жильё/энергия/снаряжение |  |  |  |  |
| Связь/официальные сообщения |  |  |  |  |
| Забота/доступность |  |  |  |  |

## Как принять решение

1. Сформулируйте вопрос одним предложением.
2. Назовите подтверждённые факты и неизвестное.
3. Проверьте тип решения по матрице: срочное защитное, срочное обратимое, плановое общее или личное.
4. Для общего решения выслушайте каждого, кого оно затрагивает, включая менее громких участников.
5. Выберите безопасный и по возможности обратимый вариант.
6. Запишите срок действия и момент пересмотра.
7. Для личного/труднообратимого вопроса не заменяйте согласие голосованием.

## Одному человеку

Проведите письменную «пятиминутку»:

1. что опасно;
2. состояние тела и усталость;
3. что изменилось;
4. какой ресурс закончится первым;
5. три результата до следующего будильника;
6. кому и когда сообщить о состоянии.

Прочитайте запись вслух: это часто выявляет размытые формулировки вроде «разобраться с водой» вместо проверяемого результата.

## Пределы собрания

- Встреча распределяет общую работу, но не является судом.
- Ведущий может прервать повторение и оскорбление, но не скрыть возражение из протокола.
- Медицинские подробности, жалобы о насилии и персональные данные не обсуждаются всей группой.
- Человек может покинуть встречу по безопасности, здоровью или уходу; ему передают итог доступным способом.
- Никакое собрание не запрещает звонок 112 или обращение за защитой.

## Контроль результата

Встреча успешна, если:

- завершилась примерно за 15 минут;
- отделила факты от сообщений;
- создала не более трёх основных целей;
- у каждой задачи есть согласившийся ответственный, помощник, срок и стоп-условие;
- важное несогласие записано без преследования;
- назначена следующая проверка;
- участники могут своими словами повторить план.

## Ошибки — так не делать

- проводить совещание в опасной зоне;
- позволять одному человеку говорить большую часть времени;
- принимать решения без записи;
- обсуждать характер и виновность вместо наблюдаемого факта и следующего действия;
- публично требовать раскрытия диагноза или травмирующей истории;
- ставить 10–20 целей, которые никто не запомнит;
- заканчивать словами «кто-нибудь сделает»;
- превращать отсутствие на встрече в лишение помощи.
