# Офлайн-набор карт Португалии и квартальная проверка

## Когда применять

- При подготовке дома, автомобиля и эвакуационной сумки.
- После переезда, открытия новой дороги, закрытия моста, изменения медицинских пунктов или официальных зон риска.
- Раз в квартал, даже если ничего не произошло.
- Перед поездкой в горы, сельскую местность, на острова или в зону слабого покрытия.

## Что хранить

Нужен не один «красивый файл», а несколько уровней, потому что одна карта не показывает всё.

| Уровень | Рекомендуемый масштаб | Для чего |
|---|---:|---|
| Дом и квартал | 1:5 000–1:10 000 | Выходы, улицы, лестницы, открытые площадки, точки встречи |
| Муниципалитет и окрестности | 1:25 000–1:50 000 | Тропы, рельеф, водотоки, запасные дороги |
| Район/округ | 1:100 000–1:250 000 | Междугородние объезды и взаимное положение населённых пунктов |
| Португалия целиком | 1:500 000–1:600 000 | Обзор, административные границы, дальний маршрут |
| Карты конкретных угроз | разный | Наводнения, цунами, пожарная опасность, оползни, закрытые зоны |

Практический минимум для одной семьи:

1. **Официальная административная карта CAOP** — чтобы точно знать freguesia, município и distrito. DGT публикует CAOP и готовую версию для печати A4.
2. **Топографические листы района проживания и запасного места**. В Португалии ориентиром служит Carta Militar de Portugal, серия M888, 1:25 000; актуальность и условия получения конкретного листа проверяйте у CIGeoE.
3. **Обзорная дорожная карта Португалии**. У CIGeoE доступна официальная дорожная карта 1:500 000 в GeoPDF.
4. **Муниципальные карты рисков и эвакуации**: ищите на сайте Câmara Municipal или Serviço Municipal de Proteção Civil. Для прибрежной зоны отдельно проверяйте маршруты и зоны эвакуации от цунами; для речных долин — затопление; для сельской местности — пожар.
5. **Карта медицинских и общественных точек**: больницы, centros de saúde, аптеки, пожарные части, PSP/GNR, муниципалитет, общественные убежища/пункты сбора, если они официально назначены.
6. **Обычная офлайн-карта улиц и троп** как вспомогательный слой. Она не заменяет официальные предупреждения и может содержать закрытые или частные дороги.

## Цифровая копия

На двух независимых устройствах храните:

- PDF/GeoPDF для чтения без специальной программы;
- офлайн-слой в приложении, которое открывает его без учётной записи и сети;
- исходные данные в открытом формате, если умеете ими пользоваться, например GeoPackage;
- снимок легенды, дату издания и лицензию рядом с файлом;
- текстовый список ключевых координат — он остаётся читаемым, даже если карта не загрузилась.

Структура папки на устройстве:

| Папка | Содержимое |
|---|---|
| 01_Дом | квартал, выходы, точки встречи |
| 02_Муниципалитет | топография, дороги, риски |
| 03_Регион | объезды и соседние муниципалитеты |
| 04_Португалия | обзорная карта и CAOP |
| 05_Маршруты | заполненные маршрутные карточки |
| 06_Контакты | адреса, телефоны, координаты |

## Бумажная копия

1. Печатайте местные карты достаточно крупно: уменьшенный лист с нечитаемыми названиями бесполезен.
2. На каждом листе подпишите дату источника, масштаб, север, систему координат и номер соседнего листа.
3. Отметьте дом и точки встречи карандашом или съёмной плёнкой; не закрывайте легенду.
4. Один комплект держите дома, второй — в сумке, третий обзорный — в автомобиле, если он есть.
5. Защитите листы прозрачными пакетами. Не ламинируйте единственный экземпляр, если на нём нужно писать.

## Квартальная проверка

Проводить в январе, апреле, июле и октябре либо каждые три месяца от даты создания.

| Проверка | Да/нет | Что исправить | Срок |
|---|---|---|---|
| Все файлы открываются в авиарежиме | | | |
| Масштаб и подписи читаемы на бумаге | | | |
| Даты и версии источников записаны | | | |
| Основной и запасной маршруты проходимы | | | |
| Мосты, дороги и тропы не закрыты официально | | | |
| Медицинские пункты и телефоны актуальны | | | |
| Точки воды проверены, а не предположены по карте | | | |
| Карты рисков муниципалитета обновлены | | | |
| У всех членов семьи есть нужный фрагмент карты | | | |
| Резервная копия находится на другом носителе | | | |

## Контроль результата

Отключите Wi‑Fi и мобильную передачу данных. За пять минут найдите:

- своё положение;
- ближайшую точку встречи;
- два безопасных пути к ней;
- ближайший медицинский пункт;
- координаты точки, которые можно продиктовать 112;
- дату и источник карты.

Если хотя бы один пункт не выполнен, комплект ещё не готов.

## Стоп-правила

- Не считайте водоём на карте источником питьевой воды.
- Не принимайте старую дорогу за проходимую: оползень, пожар, ремонт и частный статус меняют ситуацию.
- Не храните единственную карту только в телефоне.
- Не используйте скриншот без масштаба, северной стрелки и привязки к соседней территории как основную карту.
- Не распространяйте лицензированные картографические материалы вопреки условиям правообладателя.
