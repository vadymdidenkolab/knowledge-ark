# Резерв питания для связи и навигации

## Когда применять

- При подготовке аварийного комплекта.
- Перед выходом или штормом.
- Сразу после отключения электричества.
- Когда оставшегося заряда должно хватить на несколько контрольных окон.

Цель — не держать все устройства включёнными, а обеспечить последовательность: **получить предупреждение, определить место, связаться с семьёй, вызвать 112 при необходимости**.

## Минимальный набор

- основной телефон;
- резервный телефон с актуальной SIM/eSIM, если доступен;
- два проверенных powerbank вместо одного большого единственного;
- короткие совместимые кабели, подписанные по устройствам;
- сетевой адаптер и автомобильный адаптер, если есть автомобиль;
- батарейный или динамо‑радиоприёмник;
- фонарь с отдельным запасом элементов питания;
- для PMR446 — штатные аккумуляторы и/или совместимые сменные элементы;
- складная солнечная панель только как дополнение, а не гарантированный источник.

ANEPC прямо включает радио, фонарь и powerbank для телефона в аварийный комплект.

## Инвентаризация нагрузки

| Устройство | Для чего критично | Ёмкость/энергия по маркировке | Сколько реально работает | Разъём | Резерв |
|---|---|---:|---|---|---|
| Основной телефон | 112, SMS, карта | | | | |
| Резервный телефон | запас | | | | |
| Радиоприёмник | официальные сообщения | | | | |
| PMR446 | локальная связь | | | | |
| Фонарь | безопасное движение | | | | |

Если производитель указывает ватт‑часы, их удобнее сравнивать между разными батареями. Для грубой оценки:

**ватт‑часы ≈ вольты × ампер‑часы.**

Не обещайте себе точное количество зарядок по номиналу powerbank: преобразование напряжения, холод, возраст, кабель и режим телефона дают потери. Проверяйте фактическим циклом на своём устройстве.

## Режим экономии после отключения

1. Убедитесь, что все устройства заряжены, затем отключите ненужные от сети.
2. Назначьте один активный телефон; остальные выключите либо переведите в авиарежим.
3. Уменьшите яркость, выключите фоновое обновление, Bluetooth и геолокацию, когда они не нужны.
4. Используйте бумажную карту; включайте экран только на контрольных точках.
5. Установите окна связи, например каждые несколько часов по семейному плану, а не постоянную проверку.
6. Слушайте радио короткими сеансами в заранее выбранное время.
7. Один powerbank назначьте «неприкосновенным» для 112 и последнего резерва.
8. Ежедневно записывайте остаток каждого источника и прогноз, на сколько окон его хватит.

## Безопасная зарядка

- Используйте зарядное устройство и кабель, совместимые с производителем.
- Заряжайте на твёрдой негорючей поверхности, не под подушкой, одеждой или в закрытой сумке.
- Не перегружайте розетку множеством переходников.
- Не оставляйте неизвестный повреждённый аккумулятор заряжаться без наблюдения.
- Храните батареи вдали от прямого солнца, горячего автомобиля, воды и горючих материалов.
- Прекратите использование при вздутии, запахе, изменении цвета, утечке, необычном шуме или сильном нагреве.
- Не вскрывайте и не ремонтируйте литиевый пакет самостоятельно.
- Отработанные или повреждённые литиевые батареи сдавайте по правилам муниципалитета; не бросайте в обычный мусор.

Если аккумулятор дымит, шипит или быстро нагревается, отойдите, предупредите людей и вызывайте экстренные службы при пожаре. Не берите горящее устройство голыми руками и не переносите его через жилое помещение.

## Квартальная проверка

1. Осмотреть корпуса и кабели.
2. Проверить отзывы/отзыв продукции производителя и регулятора.
3. Полностью выполнить один контролируемый цикл питания каждого критичного устройства.
4. Записать фактическую отдачу, а не только проценты индикатора.
5. Проверить заряд от автомобиля и панели отдельно.
6. Заменить неисправные кабели; утилизировать батареи законным способом.
7. Убедиться, что семья знает, какой powerbank зарезервирован для экстренной связи.

## Контроль результата

- Любой взрослый за минуту соединяет основной телефон с резервным питанием.
- Карта, список контактов и координаты доступны на выключенном от сети устройстве.
- Есть минимум два независимых способа зарядить или заменить элементы.
- Фактическая автономность проверена и записана.
- Резерв распределён между сумками, а не лежит в одном контейнере.

## Стоп-правила

- Не собирайте самодельный литиевый аккумулятор из неизвестных или снятых элементов.
- Не используйте вздувшуюся, промокшую, пробитую или перегретую батарею.
- Не заряжайте устройство на пути эвакуации.
- Не расходуйте последний резерв на видео, игры, постоянный GPS‑трек или бесконечную ленту сообщений.
- Не рассчитывайте на солнечную панель без полевого теста при облаках и в нужный сезон.
