# Расчёт критических нагрузок и источников энергии

Нельзя выбирать батарею, инвертор, генератор или солнечную панель по словам «много ватт». Сначала измеряют **полезную задачу**, затем мощность, пуск, энергию за сутки, допустимый простой и сезонные условия.

Эта карточка — единое место расчёта. Выбранный источник затем проверяется по [[03 — Возобновляемая генерация — солнце, вода и ветер]], [[05 — Генератор — размещение, подключение и заправка]] или заменяется прямой механической работой по [[09 — Ручные и механические замены электрическим приборам]].

## Базовые величины и единицы

- мощность прибора: `P`, ватт (W);
- время работы: `t`, часов (h);
- энергия: `E = P × t`, ватт-часов (Wh).
- напряжение: `V`, вольт (V);
- ток: `I`, ампер (A);
- приближённо для постоянного тока: `P = V × I`;
- `1 kW = 1000 W`, `1 kWh = 1000 Wh`.

Пример: светодиодная лампа 5 W, работающая 6 часов, потребляет `5 × 6 = 30 Wh`.

`W` и `Wh` нельзя менять местами. `1000 W` говорит, какую мгновенную нагрузку выдерживает источник; `1000 Wh` — сколько энергии он хранит или отдаёт. Накопитель 1000 Wh теоретически питает 100 W десять часов, но фактически меньше из-за допустимого остатка, потерь, температуры и старения.

## Сначала определить энергетическую услугу

Записывайте не «холодильник» или «насос», а результат и предел отказа.

| Услуга | Измеряемый результат | Что делает её критической |
|---|---|---|
| поддержка медицинского прибора | Wh за полный цикл; W пуска; допустимый перерыв | индивидуальное назначение и последствия остановки |
| безопасная вода | литров/сутки при нужном напоре и качестве | отсутствие ручного пути или малый запас воды |
| холод | температура и Wh за 24–72 часа в жаркий день | лекарства или пища с ограниченным температурным диапазоном |
| связь | число сеансов/сообщений и Wh на заряд | вызов помощи и координация группы |
| свет | освещённая рабочая зона и часы | лестница, медицинская помощь, охрана от пожара |
| тепло/прохлада | температура одной безопасной зоны | возраст, болезнь, жара/холод и состояние здания |

Приоритет определяется **последствием отключения для конкретных людей и условий**, а не названием прибора. В жару охлаждение помещения для уязвимого человека может стать очередью 1.

## Три режима, которые считают отдельно

| Режим | Смысл | Что обычно остаётся |
|---|---|---|
| минимум выживания | короткий дефицит, продержаться безопасно | медицина, вода, один канал связи, локальный свет, датчики |
| устойчивый аварийный | дни или недели с ежедневным пополнением | минимум плюс рассчитанный холод, информация и малые ремонтные работы |
| рабочая автономия | сезонная жизнь и производство | минимум плюс насосы, переработка пищи, мастерская и обучение по расписанию |

Нельзя суммировать все бытовые приборы и называть это критической потребностью. Для каждой строки укажите режимы, в которых она разрешена.

## Реестр нагрузок: измерение, а не догадка

| ID | услуга и прибор | очередь 1–6 | напряжение/разъём | W работа | W пуск | цикл и часов/сутки | измерено Wh/сутки | допустимый простой | ручной/второй путь |
|---|---|---:|---|---:|---:|---|---:|---|---|
|  | медицинская услуга | 1 |  |  |  |  |  |  | только план врача и изготовителя |
|  | вода | 2 |  |  |  |  |  |  | запас/ручной насос |
|  | свет безопасной зоны | 2 |  |  |  |  |  |  | налобный фонарь |
|  | телефон/радио | 3 |  |  |  |  |  |  | бумажный план/приёмник |
|  | холодильник | 1 или 4 |  |  |  | полный цикл |  |  | холодовая тара/перемещение |

Для каждого значения укажите источник:

- `ИЗМЕРЕНО` — подходящим счётчиком в полном реальном цикле;
- `ПАСПОРТ` — из руководства точной модели;
- `ОЦЕНКА` — временное предположение, которое ещё нельзя использовать для окончательной закупки.

### Как измерять разные нагрузки

- Постоянную простую нагрузку измерять весь обычный период работы.
- Холодильник, морозильник, насос с автоматикой и прибор с термостатом — не менее полных суток в неблагоприятной температуре; лучше 72 часа.
- Телефон и power bank — от известного начального состояния до заданного конечного состояния, включая потери зарядного устройства.
- Электромедицинский прибор — только способом, не нарушающим его руководство, назначение и электробезопасность.
- Насос — одновременно записывать литры, высоту/давление, время и Wh; «насос включался 20 минут» не доказывает выполненную водную задачу.

Для компрессора, насоса или холодильника инвертор должен выдерживать не только среднюю, но и пусковую мощность. Её берут из документации или измеряют подходящим прибором; не угадывают.

## Группа от 1 до 7 человек

Часть расходов почти не зависит от числа людей: один радиоприёмник, один маршрутизатор, одна помпа. Другая часть растёт: личный свет, телефоны, объём воды, холодовая ёмкость.

Предварительная формула:

`E_группы = E_общие + n × E_на_человека + E_специальные`,

где `n` — фактическое число людей, а `E_специальные` — медицинские приборы, детское питание, уход, насос или иной индивидуальный процесс.

| Состав | Общие Wh/сутки | Wh/сутки на человека | Специальные Wh/сутки | Итого измерено | Кто зависит от нагрузки |
|---:|---:|---:|---:|---:|---|
| 1 |  |  |  |  |  |
| 3 |  |  |  |  |  |
| 5 |  |  |  |  |  |
| 7 |  |  |  |  |  |

Это не норматив. Таблица заполняется фактическими устройствами. Общий холодильник нельзя механически умножать на семь, а личные фонари нельзя оставить одной общей строкой.

## Суточный профиль

Общее `Wh/сутки` недостаточно. Запишите, **когда** возникает нагрузка: солнечная система может иметь достаточно энергии за сутки, но не выдержать одновременный вечерний пик или ночной насос.

| Час | очередь 1 W | очередь 2 W | очередь 3–4 W | заряд/ремонт W | суммарная W | источник |
|---:|---:|---:|---:|---:|---:|---|
| 00–01 |  |  |  |  |  |  |
| … |  |  |  |  |  |  |
| 23–24 |  |  |  |  |  |  |

Для нескольких двигателей вводите их по одному. Самый тяжёлый допустимый одновременный пуск становится проверкой инвертора или генератора.

## Расчёт батареи

1. Сложите измеренные Wh/сутки выбранного режима: `E_сут`.
2. Выберите число суток без достаточного пополнения: `N`.
3. Возьмите разрешённую используемую долю батареи `f_исп` из руководства точной системы.
4. Для автономии от **уже заряженной** батареи определите КПД пути отдачи `η_отдачи`: батарея, кабель, DC-преобразователь и/или инвертор между батареей и нагрузкой. Потери зарядного устройства и контроллера сюда не включайте — они относятся к отдельному расчёту мощности и энергии пополнения. Не перемножайте рекламные «до» как доказанные значения: измерьте выбранный путь.
5. Предварительная номинальная ёмкость:

   `E_акб,ном = E_сут × N / (f_исп × η_отдачи)`.

6. Если ёмкость дана в ампер-часах, только для одного известного номинального напряжения:

   `C_Ah = E_акб,ном / V_ном`.

7. Добавьте отдельно документированные поправки на температуру, старение, резерв и рост нагрузки. Не прячьте несколько запасов в одном коэффициенте.

Пример метода: нагрузка `400 Wh/сутки`, два дня, допустимо использовать `80%`, измеренный КПД пути отдачи `85%`:

`400 × 2 / (0,80 × 0,85) ≈ 1177 Wh` номинально.

Это расчётный минимум для заданных допущений, а не готовая спецификация. Пусковая мощность, максимальный ток, температура и совместимость проверяются отдельно.

### Почему одного процента заряда мало

Показание `50%` — оценка BMS, а не измерение оставшихся полезных Wh. Для принятия системы проведите контролируемый разряд известной нагрузкой в разрешённых пределах и запишите реально отданные Wh. Повторение в одинаковых условиях показывает ухудшение батареи лучше, чем случайное напряжение без нагрузки.

## Расчёт источника

### Солнечная панель: только первый набросок

`P_PV ≈ E_сут / (H_зима × η_системы)`,

где `P_PV` — требуемая пиковая мощность панелей в Wp, `H_зима` — эквивалентные солнечные часы неблагоприятного периода, `η_системы` — совокупный коэффициент потерь. `H_зима` не угадывают: окончательный расчёт делают в PVGIS для точных координат, тени, угла, азимута, батареи и часового профиля.

### Малая гидроэнергия

Предварительная электрическая мощность:

`P_эл ≈ ρ × g × Q × H_нетто × η ≈ 9810 × Q × H_нетто × η`,

где `Q` — разрешённый расход в `м³/с`, `H_нетто` — напор после потерь в метрах, `η` — общий КПД турбины, передачи, генератора и электроники.

Пример: `Q = 0,005 м³/с` (5 л/с), `H_нетто = 8 м`, `η = 0,50`:

`9810 × 0,005 × 8 × 0,50 ≈ 196 W`.

При непрерывной работе это теоретически около `4,7 kWh/сутки`, но только пока сохраняются расход, напор и допустимый режим. Считать нужно по минимальному сезонному разрешённому стоку, а не после дождя.

### Ветер

Мощность потока через ротор:

`P ≈ 0,5 × ρ_возд × A × v³ × C_p × η`,

где `P` получается в W, если `ρ_возд` задана в kg/m³, `A` — в m², а `v` — в m/s; `C_p` и `η` безразмерны. Для горизонтально-осевого ротора диаметром `D` метров: `A = π × D² / 4`. Куб скорости означает, что небольшая ошибка в `v` даёт большую ошибку мощности. Для выбора используют измерения на месте и сертифицированную кривую **годовой энергии**, а не только формулу или номинальные kW.

### Энергия подъёма воды

Минимальная энергия без учёта пуска и вспомогательных потерь:

`E_Wh = ρ × g × V_воды × H / (3600 × η)`.

Для результата в Wh здесь `ρ ≈ 1000 kg/m³`, `g ≈ 9,81 m/s²`, `V_воды` обязательно в `m³`, `H` в `m`, а `η` безразмерна. Литры сначала делят на 1000; иначе ошибка будет в тысячу раз.

Для 100 л (`0,1 м³`) на высоту 10 м при общем КПД `0,50` получается около `5,45 Wh`. Реальная система может потребовать намного больше из-за давления, трения, режима двигателя и управления — проверка идёт по измеренным Wh и реально доставленным литрам.

### Нагрев воды и солнечное тепло

`Q = m × c × ΔT`.

Для воды `c ≈ 4,186 kJ/(kg·°C)`. Нагреть 10 л воды с 20 до 60 °C в идеальном расчёте:

`10 × 4,186 × 40 = 1674,4 kJ ≈ 0,465 kWh`.

Фактически нужно больше из-за потерь. Эта формула не подтверждает санитарную безопасность воды и не разрешает самодельный герметичный/напорный коллектор.

### Топливо и полезное тепло

Если низшая теплота сгорания `LHV` дана в `MJ/kg`:

`E_полезная(kWh) = масса(kg) × LHV(MJ/kg) × η / 3,6`.

Если `LHV` дана в `MJ/L`, вместо массы используется объём в литрах. Если источник уже даёт `kWh/kg` или `kWh/L`, делить на 3,6 повторно нельзя.

Теплоту сгорания берут из документации точного топлива, КПД — из данных или испытания конкретного прибора. Для дров записывают ещё влажность и массу; складочный объём не равен массе сухого топлива.

Для генератора полезнее собственное измерение:

`удельный расход = литры топлива / произведённые kWh` при конкретной нагрузке.

## Ток, низковольтная сеть и потери

При одинаковой мощности низкое напряжение означает большой ток:

`I ≈ P / (V × η)`.

Даже без учёта потерь нагрузка 1000 W потребует около 83 A при 12 V и около 21 A при 48 V. Поэтому «всего 12 вольт» может вызвать пожар при коротком замыкании.

Основные проверки проекта:

- падение напряжения: `ΔV = I × R_петли`;
- доля падения: `100 × ΔV / V_ном`;
- тепловые потери проводника: `P_пот = I² × R`;
- допустимый ток проводника с учётом материала, сечения, длины, температуры, способа прокладки и группировки;
- отключающая способность защиты при возможном токе короткого замыкания;
- защита каждого незаземлённого проводника и источника по утверждённой схеме.

Предварительно сопротивление пары проводников можно оценить как `R_петли = ρ_эл × L_петли / A`, где `R` в Ω, `L_петли` — полная длина прямого и обратного проводников, а `A` — сечение. Единицы должны быть согласованы: например, при `ρ_эл` в `Ω·mm²/m`, длина задаётся в метрах, сечение — в `mm²`. Материал, температура, контакты, обжимы и старение добавляют сопротивление, поэтому расчёт не заменяет таблицы изготовителя, проект и измерение падения под безопасной известной нагрузкой.

Предохранитель защищает **провод и систему от аварийного тока**, а не делает слишком тонкий кабель безопасным. Номинал, тип DC/AC и отключающая способность выбираются проектировщиком и изготовителем; не увеличивайте номинал после срабатывания.

## Чем измерять

| Задача | Подходящий класс прибора | Граница |
|---|---|---|
| бытовой AC-прибор | розеточный счётчик W/Wh с подходящим номиналом | не для щита, повреждённой розетки или влажной зоны |
| готовый низковольтный контур | штатный монитор/шунт или DC-счётчик нужного диапазона | установка шунта и защиты по проекту |
| напряжение/целостность | мультиметр требуемой категории, диапазона и исправности | не измерять сеть/высокое DC без квалификации |
| ток без разрыва цепи | клещи нужного типа AC/DC | только обученным оператором и в пределах прибора |
| нагрев | контактный датчик или безопасная тепловая проверка | температура корпуса не заменяет проверку клемм специалистом |
| генератор | счётчик моточасов, Wh и мерная тара топлива | заправка только на остановленном остывшем двигателе |
| дрова | весы и влагомер древесины | измерять свежий раскол по инструкции прибора |
| безопасность горения | исправный датчик CO и дыма | не использовать бытовой датчик для входа в опасную атмосферу |

Проверьте батарею и предохранитель мультиметра до работы. Открытые солнечные строки, батарейная шина высокой энергии, электрощит, сеть 230 V и генераторный ввод — не учебная площадка для новичка.

## Расчёт на неблагоприятный сезон

Сделайте минимум четыре сценария:

1. зимний минимум солнца и короткий день;
2. летняя жара и максимальный расход холода/воды;
3. несколько дней отсутствия главного ресурса;
4. один источник или контроллер полностью отказал.

Для каждого запишите:

- `Wh/сутки` по очередям;
- максимальную одновременную W и пуск;
- источник и ожидаемую выработку;
- пригодные Wh накопителя;
- день/час достижения порога отключения;
- ручной путь и кого уведомить.

## Ошибки, которые ломают расчёт

- взять W с шильдика и назвать их Wh/сутки;
- считать холодильник по одной минуте работы;
- забыть собственное потребление инвертора, контроллера, маршрутизатора и подогрева батареи;
- сложить пуск всех двигателей, хотя проект включает их по очереди, или наоборот забыть возможный одновременный пуск;
- использовать среднегодовое солнце вместо худшего месяца;
- считать номинальные Ah разных напряжений равными;
- складывать Wh батарей, которые нельзя безопасно соединить;
- дважды применять один и тот же запас;
- считать расчёт доказательством без реального испытания.

## Проверка делом

1. Соберите систему по утверждённой схеме, штатными совместимыми компонентами.
2. Проведите 24-часовой тест каждого критического прибора и 72-часовой тест всей аварийной системы.
3. Запишите начальные и конечные Wh/заряд, полученную энергию, максимальную W, температуру, фактический полезный результат и срабатывания защиты.
4. Имитируйте отказ главного источника и полный запуск с безопасного отключённого состояния.
5. Повторите в наиболее неблагоприятном летнем и зимнем режиме.
6. Если медицинская или пожарная безопасность зависит от системы, подтвердите отдельный резерв, не использующий ту же батарею, кабель, контроллер и оператора.
7. Перенесите результат в [[11 — Журнал энергии, топлива и обслуживания]].
