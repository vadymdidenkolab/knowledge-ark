# Как пользоваться автономной картотекой знаний

Главная страница: [[00 — НАЧАТЬ|НАЧАТЬ]]. Полная карта: [[01 — КАРТОТЕКА ЗНАНИЙ/00 — Карта всех знаний|Карта всех знаний]].

## Один правильный путь

1. На странице **НАЧАТЬ** выберите свою ситуацию.
2. Маршрут покажет темы в нужной последовательности.
3. Тематическая страница объяснит, что требуется до начала, что уже имеется, чего нет и какой следующий шаг безопасен.
4. Полное руководство или источник открывайте только когда тематическая страница на него ссылается.
5. Служебные коды и таблицы используйте только для аудита и пересборки.

Обычный путь должен укладываться в три уровня:

```text
НАЧАТЬ → МАРШРУТ ПО СИТУАЦИИ → ТЕМА
```

## Основные человеческие разделы

- `01 — КАРТОТЕКА ЗНАНИЙ` — маршруты и темы, с которых начинается чтение;
- `10 — Руководства` — полные обзорные документы с русскими названиями;
- `20 — Рабочие разделы` — фактический статус, инвентарь, пробелы и офлайн-файлы.

Служебные реестры, шаблоны и автоматически созданные идентификаторы скрыты в проводнике по умолчанию, но не удалены. Это позволяет сохранять машинную проверку, не заставляя человека читать коды.

## Что означают человеческие статусы

| Видимый статус | Значение |
|---|---|
| Не готово | Нужного содержания, имущества или доказательства пока нет |
| Есть только место в системе | Тема учтена, но практического материала нет |
| Источник найден | Известно, откуда брать сведения, но локальная копия и проверка ещё не доказаны |
| Файл сохранён офлайн | Файл физически находится в библиотеке; его правильность и применимость ещё проверяются отдельно |
| Проверено человеком | Компетентный рецензент проверил указанную версию и её границы |
| Есть полный пакет выполнения | Указаны входы, инструменты, измерения, остановка и критерий результата |
| Осмотрено физически | Вещь или система реально найдена, пересчитана и осмотрена |
| Испытано | Конкретная версия прошла записанное испытание |
| Разрешено для указанного случая | Человек отдельно разрешил конкретную версию и область применения |
| Только справка — не выполнять | Теория сохранена, но бытовое исполнение не разрешено |
| Пока нельзя | Не выполнено обязательное условие безопасности или готовности |

## Граница безопасности

Наличие документа не означает, что действие безопасно. Для медицины, неизвестных растений и грибов, токсичной химии, горючих веществ, высокого напряжения, давления, тяжёлых конструкций и промышленного оборудования действуют отдельные ограничения.

- Не определять съедобность растения или гриба по фотографии, приложению или ответу искусственного интеллекта.
- Не заменять назначенное лечение непроверенной травой или грибом.
- Не превращать промышленное либо лицензируемое производство в бытовой рецепт.
- Не считать чертёж готовым без материалов, размеров, измерений, испытания и безопасного отказа.
- Не считать запас существующим, пока он не осмотрен физически.
