# Условие приватности репозитория

Этот репозиторий содержит локальные копии официальных и лицензируемых документов, для части которых полный анализ права на повторное распространение ещё не завершён.

До завершения построчной проверки `offline-library/offline-payload-register.csv` репозиторий должен оставаться **PRIVATE**. Нельзя:

- переключать видимость на public;
- публиковать архив, релиз или зеркало с содержимым `offline-library/private-licensed`;
- добавлять внешних участников без проверки объёма разрешённого доступа;
- считать доступность PDF на сайте издателя автоматическим разрешением на повторное распространение.

Текущая загрузка в приватный репозиторий является резервной копией владельца. Она не меняет статусы прав, безопасности, рецензии и выпуска, записанные в реестре.

Перед изменением видимости нужны: правовая проверка каждой строки; удаление или замена файлов без подтверждённого разрешения; проверка отсутствия персональных данных и секретов; повторная проверка всей истории Git, а не только последнего состояния.
