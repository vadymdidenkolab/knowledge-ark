# Базовый физический контур аптечек

## 1. Что это и чего это не делает

Это безопасный каркас для инвентаризации и последующей закупки. Он не является универсальным списком лекарств, не назначает дозы и не доказывает готовность без курса и теста. Окончательные количества зависят от людей, болезней, профессии, расстояния до помощи и уровня подготовки.

Целевая архитектура аптечки разделяется на четыре комплекта. Их фактическое наличие, комплектность, сроки годности и пригодность подтверждаются только заполненным физическим инвентарём и проверкой на месте:

| Комплект | Где | Задача |
|---|---|---|
| `MED-E0` | на человеке | идентификация, регулярное средство и минимальная защита |
| `MED-E1` | эвакуационный рюкзак | индивидуальная помощь до 72 часов |
| `MED-HOME` | дом | расширенная первая помощь, обычные болезни, уход и 14-дневная непрерывность |
| `MED-CAR/WORK` | машина/работа | дорожная/рабочая травма и задержка помощи с учётом условий хранения |

Профессиональные комплекты создаются отдельно для конкретной роли и службы, например `MED-M2-EMT` или `MED-M3-DENTAL`, и не смешиваются с бытовым доступом. M-код только маршрутизирует материал: доступ и применение блокируются без отдельных удовлетворённых gates для role; credential и expiry; currency и valid-until; точного scope; protocol ID/version; jurisdiction; medical direction; facility; equipment; patient-specific order, если применимо; и непросроченного gate review.

## 2. Персональная карточка — первый предмет аптечки

На каждого человека:

- [ ] имя и дата рождения;
- [ ] точный адрес и экстренный контакт;
- [ ] основные диагнозы;
- [ ] аллергии и характер тяжёлой реакции;
- [ ] лекарства: международное название, форма, назначенная доза и время;
- [ ] опасность внезапного прекращения;
- [ ] импланты и устройства;
- [ ] врач и аптека;
- [ ] страхование;
- [ ] языки общения;
- [ ] группа крови только если подтверждена документом; в экстренной помощи всё равно требуется проверка;
- [ ] дата обновления карточки.

Одна копия водостойко хранится при человеке, другая — в домашнем пакете, третья — в защищённом цифровом архиве.

## 3. Регулярные лекарства и индивидуальные средства

На каждого:

- [ ] лекарства только в оригинальной маркированной упаковке;
- [ ] законно согласованный резерв;
- [ ] копия рецепта/назначения;
- [ ] график FEFO и пополнения;
- [ ] условия температуры, света и влажности;
- [ ] дата открытия жидкостей/капель/суспензий;
- [ ] холодильный контейнер и температурный индикатор, если требуется;
- [ ] источник резервного охлаждения/энергии;
- [ ] уже назначенное средство спасения и инструкция конкретного устройства;
- [ ] диабетические, стома-, катетерные, кислородные и иные расходники только для существующего ухода;
- [ ] запасные очки;
- [ ] батареи слухового аппарата;
- [ ] средства мобильности и их запчасти;
- [ ] письменный план дефицита от врача/фармацевта.

Не заменять препарат самостоятельно по названию класса, не делиться рецептурным и не считать просроченное автоматически пригодным.

## 4. Барьерная защита и гигиена

- [ ] нитриловые перчатки нескольких подходящих размеров;
- [ ] защита глаз;
- [ ] маски/респираторы под конкретный риск и посадку;
- [ ] средство гигиены рук;
- [ ] мягкое мыло;
- [ ] питьевая вода или предназначенный для ран раствор для безопасной ирригации;
- [ ] одноразовые салфетки/полотенца;
- [ ] пакеты для загрязнённых материалов;
- [ ] контейнер для острых предметов только если они используются в назначенном уходе;
- [ ] маркировка чистой/грязной зоны;
- [ ] инструкция безопасного снятия PPE.

Перчатки не заменяют мытьё рук; респиратор от частиц не защищает от газов и дефицита кислорода.

## 5. Малые раны и перевязки

Собрать по размерам и типам:

- [ ] пластыри для малых ран;
- [ ] стерильные марлевые салфетки;
- [ ] неприлипающие покрытия;
- [ ] рулонная марля;
- [ ] медицинский фиксирующий пластырь, переносимый кожей;
- [ ] эластичные/когезивные бинты;
- [ ] косынки;
- [ ] безопасная ирригация;
- [ ] пинцет;
- [ ] травматические ножницы;
- [ ] одноразовые холодовые пакеты по необходимости;
- [ ] чистые пакеты для отрезанного/загрязнённого материала;
- [ ] карточка признаков инфекции и срочного направления;
- [ ] журнал даты, места, очистки, повязки и изменений.

Количество рассчитывается не «по одной штуке», а на несколько полных смен повязки для каждого реалистичного случая до пополнения. Глубокие, укушенные, сильно загрязнённые, колотые и расходящиеся раны требуют ранней профессиональной оценки; домашнее ушивание не входит.

## 6. Массивное наружное кровотечение

Только как связка **сертифицированное средство + очное обучение + практика**:

- [ ] крупные марлевые/давящие материалы;
- [ ] сертифицированный турникет конкретной модели;
- [ ] гемостатический материал, если входит в пройденный протокол;
- [ ] маркер/способ записать время;
- [ ] термозащита;
- [ ] ножницы;
- [ ] перчатки и защита глаз;
- [ ] карточка текущего ERC/пройденного курса;
- [ ] учебный экземпляр отдельно от рабочего;
- [ ] журнал срока, упаковки и тренировок.

Не покупать неизвестную копию критического изделия. Не учиться впервые на реальном пострадавшем. Не ослаблять/снимать применённый турникет самостоятельно вне протокола профессиональной помощи.

## 7. Травма и иммобилизация

- [ ] косынки;
- [ ] эластичные бинты;
- [ ] шина, если обучены её применять;
- [ ] мягкая подкладка;
- [ ] холодовой пакет;
- [ ] термоодеяло/средство уменьшить теплопотерю;
- [ ] прочное покрывало/средство перемещения только по навыку;
- [ ] блокнот для механизма, времени, сознания, боли и изменений;
- [ ] фонарь;
- [ ] карточка 112 и передачи.

Не вправлять вывих/перелом, не удалять застрявший предмет и не выполнять опасное перемещение без непосредственной угрозы.

## 8. Ожоги и глаза

- [ ] доступ к достаточному объёму чистой воды для охлаждения/промывания;
- [ ] раствор/система промывания глаз;
- [ ] неприлипающие стерильные покрытия;
- [ ] свободная фиксация;
- [ ] чистое покрывало/термозащита;
- [ ] карточка химического продукта/SDS для реально хранимых веществ;
- [ ] перчатки и защита глаз для помощника;
- [ ] запасная чистая одежда и пакеты для загрязнённой.

Не использовать лёд, масло, муку, зубную пасту и случайные кремы. Не нейтрализовать кислоту щёлочью или наоборот. Электрические, химические, большие, глубокие, ингаляционные ожоги и ожоги особых зон требуют срочной помощи.

## 9. Температура и наблюдение

Базово:

- [ ] надёжный термометр и запас питания;
- [ ] часы/таймер;
- [ ] блокнот наблюдения;
- [ ] инструкция нормального использования прибора;
- [ ] запасные батареи.

По персональной цели и навыку:

- [ ] тонометр с подходящей манжетой;
- [ ] пульсоксиметр;
- [ ] глюкометр, полоски, контрольный раствор, ланцеты и sharps-контейнер;
- [ ] медицинский термоиндикатор;
- [ ] весы.

Прибор не ставит диагноз сам. Нормальная цифра не отменяет тяжёлые симптомы; необычная цифра сначала проверяется правильной техникой, но не задерживает 112 при красных флагах.

## 10. Пероральная регидратация и обычные симптомы

- [ ] коммерческие пакеты oral rehydration salts с понятным объёмом разведения;
- [ ] точная чистая ёмкость нужного объёма;
- [ ] безопасная вода;
- [ ] этикетка срока после приготовления;
- [ ] персонально допустимые безрецептурные средства в оригинальной упаковке;
- [ ] мерное устройство производителя;
- [ ] список противопоказаний, аллергий и взаимодействий;
- [ ] отдельная педиатрическая проверка по массе и форме — только из официального источника;
- [ ] карточка красных флагов обезвоживания/диареи/лихорадки.

Не публиковать одну универсальную таблеточную аптечку. Конкретные OTC проверяются врачом/фармацевтом для состава домохозяйства. Не смешивать порошок ORS с произвольным объёмом и не измерять детские препараты кухонной ложкой.

Отдельный `M1`-модуль может содержать first-aid лекарства/устройства только при `gate_decision=ALLOW`: действующий очный курс/сертификат, точный реально отработанный навык, актуальный protocol ID+version и юрисдикция имеют `REQUIRED_SATISFIED`; остальные gates явно `NOT_REQUIRED` либо также удовлетворены. Пустое поле, просрочка, `MISSING` или `UNKNOWN` означает `DENY`. Дополнительно нужны оригинальная упаковка, условия применения, противопоказания и юридическая проверка; позиция не добавляется в общий набор только по совету из интернета.

## 11. Аллергия, астма, диабет, судороги и другие персональные модули

Создаются только при реальной потребности:

- [ ] индивидуальный план;
- [ ] назначенное средство и запас;
- [ ] обучение самого человека и помощника;
- [ ] срок/температура;
- [ ] красные флаги;
- [ ] 112 и маршрут;
- [ ] дубликат на работе/в школе, если законно и согласовано;
- [ ] документированное разрешение caregiver/школы;
- [ ] энергетический резерв для устройства.

Чужое назначенное средство не становится универсальным содержимым общей аптечки.

## 12. Стоматологический модуль

- [ ] зубные щётки и фторсодержащая паста по индивидуальной переносимости;
- [ ] межзубная гигиена;
- [ ] мягкий воск для травмирующих ортодонтических элементов;
- [ ] чистая ёмкость и материал для транспортировки выбитого постоянного зуба по актуальной IADT-карточке;
- [ ] марля для кровотечения;
- [ ] индивидуально допустимое обезболивание;
- [ ] контакт обычного и срочного стоматолога;
- [ ] карточка опасного отёка, дыхания/глотания, лихорадки и травмы.

Не включать инструменты самостоятельного удаления, сверления, разреза абсцесса или инъекционной анестезии.

## 13. Особые группы

### Ребёнок

- [ ] точная масса и дата измерения;
- [ ] детская форма назначенных средств;
- [ ] педиатрическая медицинская карточка;
- [ ] запас ухода/питания;
- [ ] отдельный BLS/удушье курс;
- [ ] контакт педиатра/школы;
- [ ] безопасное хранение всей аптечки.

### Беременность/новорождённый

- [ ] срок беременности и обменная карта;
- [ ] роддом/акушер и два маршрута;
- [ ] назначения;
- [ ] план раннего выезда;
- [ ] базовые чистые материалы поддержки до приезда помощи по курсу/112;
- [ ] тепло для новорождённого;
- [ ] карта опасных признаков.

### Пожилой/инвалидность

- [ ] лекарства и полипрагмазия;
- [ ] очки/слух/батареи;
- [ ] мобильность и перенос;
- [ ] недержание/кожа/пролежни;
- [ ] питание/глотание;
- [ ] делирий/деменция и идентификация;
- [ ] второй помощник;
- [ ] доступный транспорт.

### Животное

- [ ] ветеринарная карточка, вакцинация и микрочип;
- [ ] назначенные препараты;
- [ ] поводок/намордник/переноска по виду;
- [ ] перчатки и средства безопасной фиксации;
- [ ] ветеринар/токсикологический маршрут;
- [ ] отдельные расходники, не смешиваемые с человеческими.

## 14. Документация внутри аптечки

- [ ] ламинированный индекс по модулям;
- [ ] карта размещения;
- [ ] медицинские карточки;
- [ ] 112/SNS24/CIAV;
- [ ] дата последней проверки;
- [ ] сроки/партии;
- [ ] температурные условия;
- [ ] журнал расхода;
- [ ] форма передачи SAMPLE/SBAR;
- [ ] карандаш/маркер;
- [ ] current guideline IDs;
- [ ] точная role-маркировка профессионального содержимого и вложенная gate-карта: ответственный, квалификация, scope, протокол/версия, юрисдикция, супервизия, площадка/оснащение и stop-условия.

## 15. Что сознательно не входит в бытовую базу

- хирургические наборы;
- шовный материал как приглашение к домашнему ушиванию;
- IV/IO-доступ и инфузии;
- инъекционные антибиотики/анестетики/антидоты;
- кровь и переливание;
- продвинутые дыхательные пути;
- ручная дефибрилляция;
- кислород без назначения, пожарной безопасности и обучения;
- акушерские инструменты;
- стоматологическое удаление/сверление;
- препараты CBRN «на всякий случай»;
- несертифицированные копии критических изделий;
- россыпь таблеток без упаковки и назначения.

Такие материалы могут существовать только в раздельных профессиональных модулях конкретной службы и конкретной роли, например `M2-EMT`, `M3-DENTAL`, `M3-OB`, `M3-SURGERY` или `M4-CBRN-SYSTEM`. Метка слоя сама по себе не является допуском. Для каждого модуля обязательны: ответственный исполнитель; credential с expiry; отдельная currency с valid-until; точный scope; protocol ID/version; jurisdiction; medical direction/супервизия; facility; полный equipment; patient-specific order, если применимо; режим доступа/учёта и gate review due. Если любой обязательный gate отсутствует, неизвестен или просрочен, содержимое не применяется.

## 16. Как рассчитать количество

После анкеты определить:

- число людей и животных;
- срок до реального пополнения;
- число регулярных перевязок/процедур существующего ухода;
- профессиональные/бытовые риски;
- удалённость 112 и доступ к транспорту;
- температурный режим;
- срок и упаковку каждого расходника;
- возможность безопасной ротации;
- распределение по E0/E1/HOME/CAR/WORK;
- резерв, не уничтожаемый одним событием.

Для расходника формула:

```text
целевое количество = обычный подтверждённый расход до пополнения
                    + сценарный расход первой помощи
                    + явно записанный резерв
```

Сценарный расход не угадывается: он задаётся после выбора покрываемых событий и консультации инструктора/клинициста.

## 17. Приёмка аптечки

Аптечка готова только если:

- [ ] каждая позиция пересчитана;
- [ ] нет просроченного/повреждённого/сомнительного;
- [ ] чувствительное хранится правильно;
- [ ] открывается одной рукой/в перчатках там, где нужно;
- [ ] находится в темноте;
- [ ] на каждом месте есть индекс;
- [ ] профессиональные средства отделены;
- [ ] минимум два человека знают размещение;
- [ ] пройден очный курс;
- [ ] проведено безопасное упражнение;
- [ ] расход заносится в журнал;
- [ ] назначена следующая проверка;
- [ ] аптечка доступна взрослому, но защищена от ребёнка/животного;
- [ ] E1 проверен по массе;
- [ ] автомобильный комплект не содержит температурно уязвимое без обоснования.

Раздельные состояния: lifecycle предметов (`planned/present/in_service/expired/quarantined`); category-specific evidence с методом, результатом и ограничениями; training simulation; и независимый `gate_decision`. «Проверено» без типа доказательства не используется. Устойчивая готовность возможна только при обслуживаемом lifecycle, подходящем evidence и, для action-linked содержимого, непросроченном `gate_decision=ALLOW`; одно из этих состояний не заменяет другое.
